# OOP Assignment 2 — SRP, Design Patterns & Inheritance

This repository contains the four parts of the Advanced .NET Engineering Diploma assignment.

## Part 1 — Single Responsibility Principle (SRP)

The `SRP/` folder contains the SRP lab, the refactored classes, and `Responsibilities.md`, which documents the responsibilities identified during the refactoring.

## Part 2 — Design Patterns

The `DesignPatterns/` folder contains implementations of the Singleton, Prototype, and Builder design patterns, along with the related runner project and LinkedIn post links in `linked.md`.

## Part 3 — Inheritance

The `Inheritance/` folder contains the Library System implementation, its class diagram, and the test scenarios in the program.

## Part 4 — LeetCode

The `LeetCode/1456_MaxVowelsInSubstring/` folder contains the solution for LeetCode 1456, an accepted-submission screenshot, and the submission link.

**Problem:** Maximum Number of Vowels in a Substring of Given Length

**Approach:** Sliding Window

## Repository Structure

- `SRP/` — Single Responsibility Principle
- `DesignPatterns/` — Design Patterns
- `Inheritance/` — Inheritance and Library System
- `LeetCode/` — Sliding Window problem solution
